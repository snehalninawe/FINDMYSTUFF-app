# FindMyStuff Web Application

## Project Overview

FindMyStuff is a web-based platform designed to help users report, search, and recover lost items efficiently. The application provides a centralized system where users can post details of lost items, search for reported items, and connect with item owners.

## Features

* User Login and Authentication
* Lost Item Reporting
* Item Search Functionality
* Item Request Submission
* Image Upload Support
* Form Validation
* Responsive User Interface
* Mobile-Friendly Design

## Technology Stack

### Frontend

* React.js

### Backend

* Django
* Django Rest Framework

### Database

* PostgreSQL

### Deployment

* Vercel/Render

## Functional Modules

### Login Module

Allows registered users to access the application securely.

### Lost Item Reporting Module

Enables users to submit details of lost items along with images and descriptions.

### Search Module

Allows users to search for lost items using keywords and filters.

### Request Item Module

Users can submit requests for items they are trying to locate.

### Validation Module

Ensures mandatory fields are completed and invalid data is rejected.

### Responsive Design

Provides compatibility across desktop, tablet, and mobile devices.
